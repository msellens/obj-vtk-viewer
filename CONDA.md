
## Conda Installation

To get the latest miniconda 
```
curl -O https://repo.anaconda.com/miniconda/Miniconda3-latest-MacOSX-arm64.sh
```
Potentially verify that the download is valid. Then run the bash file from where it was downloaded, here assume ~
```
bash ~/Miniconda3-latest-MacOSX-arm64.sh
source ~/.zshrc
```
Instructions sourced from [here](https://www.anaconda.com/docs/getting-started/miniconda/install/mac-cli-install)
